A one-line review of the humble **twist tie** — the little wire that seals a bread bag and gives up after three twists.

> "A twist tie's entire job is keeping bread fresh, yet it snaps on the third twist, leaving the bag open like it never even met the bread."

The joke is the object itself: a twist tie has exactly one job, and it quits doing it almost immediately, so the bread goes stale anyway.

## Run it

```sh
python3 main.py
```

This writes the one-line review to `/output/entry.txt` — plain UTF-8 text, no trailing newline, always byte-identical on every run.
